========================================
喫煙記録カウンター PWA - 導入・公開ガイド
========================================

■ 同梱ファイル一覧
1. index.html    : アプリ本体（画面・計算・JSON書き出し/読み込み機能内蔵）
2. manifest.json : PWAインストール設定ファイル
3. sw.js         : オフライン動作のためのService Worker
4. icon-192.png  : アプリアイコン（標準）
5. icon-512.png  : アプリアイコン（高解像度）
6. icon-maskable-512.png : Android用アイコン（余白付き）

■ スマートフォンのホーム画面にPWAとして追加する手順
1. 解凍した「smoking_pwa」フォルダを用意します。
2. パソコンまたはスマホのブラウザで https://app.netlify.com/drop を開きます。
3. 点線枠内に「smoking_pwa」フォルダをそのままドラッグ＆ドロップ（またはアップロード）します。
4. 発行された専用URLをスマートフォンのブラウザで開きます。
   - iPhone (Safari) の場合：画面下の共有ボタン（□に↑）→「ホーム画面に追加」をタップ
   - Android (Chrome) の場合：右上のメニュー（︙）→「アプリをインストール」または「ホーム画面に追加」をタップ

■ JSONファイルの書き出し・読み込みについて（iPhone対応）
アプリ下部メニューの「データ」タブから、いつでも記録をJSONファイルとして書き出し・読み込みできます。
- iPhoneでは「iPhoneの『ファイル』に保存（共有メニュー）」または「JSONファイルを書き出す」をタップし、「"ファイル"に保存」を選ぶことでiPhone本体やiCloud Driveにローカル保存できます。
- 読み込み時は「JSONファイルを選択して読み込む」からファイルを選ぶと、「現在の記録と合体する」または「上書きして置き換える」を選択できます。

■ 重要：データの保存場所について（iPhone）
記録はブラウザ内（localStorage）に保存されます。iPhoneでは「Safariのタブ」と「ホーム画面に追加したアプリ」でデータが別々になります。
- すでにSafariで記録を始めている場合は、ホーム画面に追加する前に「データ」タブでJSONを書き出し、追加後のアプリ側で「JSONファイルを選択して読み込む」から復元してください。
- ホーム画面に追加せずSafariだけで使い続けると、長期間開かない場合にデータが消去されることがあります。ホーム画面への追加と、定期的なJSON書き出しをおすすめします。

■ 更新について
sw.js は「キャッシュ優先＋裏で更新」方式です。ファイルを差し替えて再公開した場合、新しい内容は2回目の起動時に反映されます。
